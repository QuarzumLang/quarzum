# Welcome to Quarzum

Quarzum is a compiled programming language for general purpose. It is simple, minimal and extremely fast and robust.

## Features

- Object-oriented features (structures, methods, traits)
- Functional programming features (lambda functions)
- Deterministic memory allocation management
- Tuples as immutable structures inside the language
- Builtin optimized strings

## How to install Quarzum

To install Quarzum, we recommend to download and install our latest release.

> [!NOTE]
> Quarzum is not yet available to install

## Build Quarzum

First, download this repository. Then, with a Quarzum version already installed, run in a shell:

```sh
cd src
quarzum build ./quarzum.qz
```
